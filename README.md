# Angular E-commerce Frontend

A simple e-commerce frontend application built with **Angular 19** and **Angular Material**.  
It uses the [FakeStoreAPI](https://fakestoreapi.com/) to fetch product data.

## Features

- 🛒 Product listing with:
  - Search bar
  - Category filter
  - Responsive product cards
- 🔍 Product details page
- 🧺 Shopping cart with:
  - Add/remove items
  - Total price calculation
- Routing enabled (no authentication required)

---

## Tech Stack

- Angular 19
- Angular Material
- TypeScript
- SCSS
- FakeStoreAPI

---

## Getting Started

1. Clone the repository
git clone https://github.com/VishalRj-7/Talentica-Ecommerce-Frontend-1.git
cd ecommerce-app

2. Install dependencies
npm install

3. Run the app
ng serve
App will run at: http://localhost:4200
